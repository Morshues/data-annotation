# CLAUDE.md

## Language Rules

- Always communicate with the user in Traditional Chinese (Taiwan), using Taiwan-standard terminology (e.g. 程式, 檔案, 資料庫).
- All plans, explanations, progress summaries, and final reports must use Traditional Chinese.
- Technical identifiers, source code, comments, API names, and database identifiers should remain in English.
- Git commit messages and PR descriptions should be in English.
- Documentation under docs/ should use Traditional Chinese.
- Keep explanations concise and avoid repeating information.
